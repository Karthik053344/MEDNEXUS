# Security

Do not use this repository with real protected health information as-is.

Before production healthcare use, implement:
- strong authentication
- RBAC/ABAC
- tenant isolation
- encryption
- secret management
- secure object storage
- audit logs
- rate limiting
- CSRF protection where applicable
- dependency scanning
- container scanning
- penetration testing
- incident response
- data retention/deletion
- backup and disaster recovery

Report security issues privately to the project maintainer.
